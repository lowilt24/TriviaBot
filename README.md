# TriviaBot

Bot de trivia por consola, construido en Python como proyecto de aprendizaje en sesiones cortas.

## Cómo correr

```bash
python3 main.py
```

## Progreso

- [x] Sesión 1 — input/output y condicionales: preguntas con puntaje
- [x] Sesión 2 — listas, diccionarios y loops: banco de preguntas + orden aleatorio
- [ ] Sesión 3 — funciones y módulo random: lógica limpia, categoría/dificultad
- [ ] Sesión 4 — archivos JSON: banco de preguntas externo
- [ ] Sesión 5 — requests/APIs: preguntas desde Open Trivia DB
